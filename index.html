LLM agents

Multi-Agent Investment Analysis

AI agents research a stock, analyze its price trends, write a Buy/Hold/Sell report and review each other's work. A person approves the report before anything is saved.

What I learnedMy first version produced convincing reports, until I traced the data and found the writer was getting the agents' requests for data, not the data itself. Every layer after that exists to catch failures that look right.

  • Guardrails, an audit log and human approval decide where the agents' autonomy stops.
  • An evaluation gate over 10 tickers blocks any release below 90% completion or 80% grounding (report numbers traced to source data), or above $0.05 per run or 2 minutes.
  • Prompts are versioned like code, with a deployment gate and one-setting rollback.
  • FastAPI service with per-customer API keys, rate limits and 1-hour caching, 59 passing tests in CI, and a Dockerfile.

Data warehouse

Airbnb Pipeline with Snowflake and dbt

Raw listings, hosts and bookings become analytics-ready tables in Snowflake, through a Bronze, Silver and Gold medallion design built entirely in dbt.

  • Ingests 5,700 records across 3 source tables with incremental dbt models: watermark-filtered Bronze, merge-based Silver.
  • Three SCD Type 2 snapshots keep point-in-time history of every booking, host and listing.
  • Used dbt's check snapshot strategy because the sources have no updated_at, so timestamp-based change detection couldn't work.
  • Four reusable Jinja macros and loop-generated joins build the Gold one-big-table and fact models.

Cloud lakehouse

AdventureWorks Lakehouse on Azure

An end-to-end Azure pipeline that takes retail sales data from source to Power BI dashboard, answering how sales perform across products, regions and customers over time.

  • One parameterized Data Factory pipeline, driven by JSON config, ingests 10 source files; a new table is a config change, not a new pipeline.
  • Models 6 dimensional entities: sales, customers, products, territories, returns and calendar.
  • Gold views use CREATE OR ALTER, so the serving layer can be redeployed safely any number of times.
  • Secrets live in Key Vault, and Power BI connects through a read-only login with least privilege.
