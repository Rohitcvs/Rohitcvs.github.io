Multi-Agent Investment Analysis

AI agents research a stock, analyze its price trends, write a Buy/Hold/Sell report and review each other's work. A person approves the report before anything is saved.

My first version produced convincing reports, until I traced the data and found the writer was getting the agents' requests for data, not the data itself. Every layer after that exists to catch failures that look right.

  • Guardrails, an audit log and human approval decide where the agents' autonomy stops.
  • Evaluations over 10 tickers score grounding: whether the report's numbers appear in the source data.
  • Prompts are versioned like code, with a deployment gate and one-setting rollback.
  • FastAPI service with per-customer API keys and rate limits, 59 tests in CI, and a Dockerfile.

Airbnb Pipeline with Snowflake and dbt

Raw listings, hosts and bookings become analytics-ready tables in Snowflake, through a Bronze, Silver and Gold medallion design built entirely in dbt.

  • Incremental models and SCD Type 2 snapshots keep point-in-time history of every change.
  • Used dbt's check snapshot strategy because the sources have no updated_at, so timestamp-based change detection couldn't work.
  • Custom macros and Jinja-generated SQL build the wide one-big-table and fact models.

AdventureWorks Lakehouse on Azure

An end-to-end Azure pipeline that takes retail sales data from source to Power BI dashboard, answering how sales perform across products, regions and customers over time.

  • Parameterized Data Factory pipelines, so a new source table is a config change, not a new pipeline.
  • Gold views use CREATE OR ALTER, so the serving layer can be redeployed safely any number of times.
  • Secrets live in Key Vault, and Power BI connects through a read-only login with least privilege.

Customer Shopping Behavior Analysis

A full analytics workflow on 3,900 retail purchases: cleaning in Python, 10 business questions in SQL, and a Power BI dashboard with recommendations.

  • Found that subscribers don't spend more per order ($59.49 vs. $59.87), so the subscription program isn't lifting basket size.
  • 43% of purchases used a discount, which flags a margin risk worth watching.
